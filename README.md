\# 校团委排课系统使用说明



本程序用于自动化生成校团委排班表，基于人员的空闲时间和特定频率（优先级）智能分配任务。



\## 一、 运行环境准备

1\. 确保电脑已安装 Python 环境（建议 Python 3.8 及以上版本）。

2\. 安装必要的依赖库。在命令行（终端）中运行以下命令：

&#x20;  ```bash

&#x20;  pip install pandas openpyxl

&#x20;  ```



\## 二、 文件准备与目录要求

请确保以下文件与程序脚本（`.py` 文件）位于\*\*同一个文件夹（目录）\*\*下，且在执行程序前\*\*必须关闭所有相关的 Excel 文件\*\*（否则会导致文件占用无法保存）。



\### 1. 基础数据文件：`空课表\&部门人员.xlsx`

此文件是排课的核心数据源，必须包含以下三个工作簿（Sheet），且需注意数据位置：

\*   \*\*`部门` 工作簿\*\*：

&#x20;   \*   第 1 列（A列）记录\*\*部门名称\*\*（如：办公室、学科竞赛中心）。

&#x20;   \*   第 3 列（C列）记录\*\*人员姓名\*\*。

&#x20;   \*   \*(程序会自动跳过表头行，如第一行是标题会自动识别)\*。

\*   \*\*`空课表` 工作簿\*\*：

&#x20;   \*   记录每个人在特定时间段的空闲状态。

&#x20;   \*   程序只会读取 \*\*B2 到 F5\*\* 这个区域（即 4 行 5 列）的单元格。

&#x20;   \*   单元格内若有多个姓名，请用空格、逗号、顿号或换行符隔开（如：`张三 李四，王五`）。

\*   \*\*`模板` 工作簿\*\*：

&#x20;   \*   这是最终排课表的格式模板。

&#x20;   \*   程序会将排课结果填入该模板的 \*\*B3 到 F6\*\* 区域（即 4 行 5 列）。



\### 2. 目标文件：文件 C（如：`某月日程表.xlsx`）

\*   这是用来统计人员工作负荷/出现频率的文件。

\*   程序会读取该文件的\*\*第一个工作簿\*\*，统计表格中所有人名出现的次数。出现次数越少的人，在排课时的优先级越高。



\## 三、 操作步骤

1\. 运行 Python 脚本，界面上将弹出“校团委排课系统”窗口。

2\. 点击左上角的 \*\*“选择目标文件(C)”\*\* 按钮，在弹出的窗口中选择准备好的文件 C（如 `某月日程表.xlsx`）。

3\. 确认文件名显示为绿色后，点击右上角的 \*\*“开始排课”\*\* 按钮。

4\. 观察界面：

&#x20;   \*   \*\*进度条\*\*：显示当前的排课进度。

&#x20;   \*   \*\*表格展示区\*\*：实时显示 B3-F6 单元格填入的人员名单。

&#x20;   \*   \*\*日志区\*\*：显示详细的操作日志和警告（如果某个时间段实在找不到空闲人员，会提示“无合适人选”）。

5\. 排课完成后，系统会自动在程序同目录下生成一个名为 \*\*`排课表-年月日时分秒.xlsx`\*\* 的新文件。打开该文件即可查看最终结果。



\## 四、 程序核心排课逻辑（请注意核对数据）

1\. \*\*优先级生成（列表B）\*\*：

&#x20;  \*   程序汇总所有部门人员，去文件 C 中统计他们的出现次数。

&#x20;  \*   \*\*按出现次数由低到高排序\*\*。如果出现次数一样，程序会\*\*随机打乱\*\*这些人的顺序。

2\. \*\*坐标映射关系\*\*：

&#x20;  \*   模板的 \*\*B3\*\* 单元格，对应读取 `空课表` 的 \*\*B2\*\* 单元格的空闲人员。

&#x20;  \*   模板的 \*\*F6\*\* 单元格，对应读取 `空课表` 的 \*\*F5\*\* 单元格的空闲人员。

&#x20;  \*   即：\*\*模板行号 = 空课表行号 + 1\*\*。

3\. \*\*占位与剔除\*\*：

&#x20;  \*   遍历单元格时（从 B 列到 F 列，从上到下），程序会根据优先级列表（列表B），依次检查候选人是否有空。

&#x20;  \*   找到第一个有空的人后，填入格式：`人名（校团委部门名称）`。

&#x20;  \*   \*\*一旦被选中，该人员将从优先级列表（列表B）中被彻底剔除\*\*，保证在本次排课中不会被重复安排到其他时间段。



\## 五、 常见问题排查

\*   \*\*提示“找不到文件 空课表\&部门人员.xlsx”\*\*：请检查该文件是否和 `.py` 脚本放在了同一个文件夹内，且文件名一字不差。

\*   \*\*生成的文件中某些单元格显示“无合适人选”\*\*：说明在该时间段对应的 `空课表` 中，所有有空的人要么已经被排到了其他时间段（被剔除了），要么根本没有人在该时间段有空。请检查 `空课表` 原始数据是否充足。

\*   \*\*排课结果全为空或部分为空\*\*：请检查 `空课表` 的 B2:F5 区域是否有数据；或者检查 `部门` 表中的姓名列是否放在了第 3 列（C列）。

\*   \*\*报错 `PermissionError`\*\*：说明您没有关闭原来打开的 Excel 文件（尤其是文件C或基础表格），请关闭所有 Excel 窗口后重试。
