# 校团委排班系统 (值班表-v1.2) 使用说明

本程序用于自动化生成校团委排班表。程序会根据“空课表”匹配空闲人员，并根据“之前排班表”中各人员的出现次数，**优先安排出现次数较少的人员**，实现智能、公平的排班。

---

## 一、 准备工作

请确保以下文件与程序脚本（`值班表-v1.2.py`）位于**同一个文件夹（目录）**下，并提前安装好 Python 环境（依赖 `pandas` 和 `openpyxl` 库）。

### 目录文件说明：
*   📄 **`值班表-v1.2.py`**：主程序文件。**双击运行**即可使用。
*   📊 **`空课表&部门人员.xlsx`**：基础数据文件（**此文件不用改**）。
    *   必须包含名为 `部门`、`空课表`、`模板` 的三个工作簿。
    *   程序将读取 `空课表` 中 `B2:F5` 范围的空闲人员，并填入 `模板` 的 `B3:F6` 区域。
*   📊 **`排班表.xlsx`**：上一次的排班结果。
    *   **注意：每次使用前都要更新一下此文件**，确保它是最新的一期排班表。程序需要读取这个文件来统计每个人的排班次数（C文件）。因为随机的时候是按照之前排班的次数优先选择少的人来的。
*   📄 **其他文件**：如 `校团委空课表(...).xlsx` 和 `readme.md` 等，作为参考或说明文件，不影响程序运行。

---

## 二、 操作步骤

1.  **双击运行程序**
    双击 `值班表-v1.2.py`，弹出“校团委排班系统”的运行界面。

2.  **选择之前的排班文件 (C文件)**
    *   在界面左上角，点击 **“选择之前的排版文件文件(C)”** 按钮。
    *   在弹出的窗口中，选择您刚刚更新好的最新一期 **`排班表.xlsx`**。
    *   选择成功后，文件路径处会显示绿色的文件名。

3.  **开始排班**
    *   点击界面右上角的 **“开始排班”** 按钮。
    *   此时可以看到进度条开始走，界面中间的表格会**实时展示**排班生成的动态过程，底部的日志区会显示具体填入的人员信息。

4.  **获取结果**
    *   排班完成后，程序会在同目录下自动生成一个名为 **`排班表-年月日时分秒.xlsx`** 的新文件（例如：`排班表-20261023225316.xlsx`）。
    *   打开这个新生成的文件，**手动修改一下表头的日期和第几周**，即可直接使用。

---

## 三、 常见问题与注意事项

*   **💡 排班公平性说明**：因为程序是按照“之前排班的次数”优先选择次数少的人，同次数的人则是随机打乱，所以**每次运行前务必选中最新的一期排班表**作为依据。
*   **⚠️ 文件占用报错**：点击“开始排班”前，请确保没有在后台用 Excel 打开基础数据和目标排班表，否则会提示保存失败。
*   **🔄 生成失败怎么办**：如果提示生成失败，**重新来一遍就行了**（关掉程序再双击打开重试）。
*   **数据格式要求**：`空课表&部门人员.xlsx` 的格式必须严格遵循之前的设定，`空课表` 中 B2 到 F5 单元格内的人名需用空格、逗号、顿号或换行隔开。
